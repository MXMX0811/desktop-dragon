# 新角色姿态与动作设计模板

用途：新姿态、新动作与影响共用部件的修改必须使用本模板。在精修静态图前填完第 1–5 项；粗稿跑通动作后，再精修与验收。适用于任意角色、比例和姿态。只保留本动作实际需要的字段；已有动作的小修可在原设计记录中补充受影响项，不重复新建文档。

设计依据：[二维角色动作与分层素材设计手册](animation-design-guide.md)。填写后的文档与该动作素材放在一起，作为绘制和动画的共同输入。

## 3. 结构与关键姿势

- **支撑与重心**：地面/座面/桌面位置，承重部位，何时转移支撑。
- **关节链**：按角色自身左右标记肩肘腕或髋膝踝；其他生物按其结构标记。附一张去除衣物遮挡的结构草图。
- **接触点与朝向**：手掌/脚/身体接触位置、接触面的方向，以及接触开始与解除时刻。
- **肢段与体积**：对照双侧肩根、上下臂和手，或髋、大小腿和脚；哪些投影长度随透视变化，哪些宽度、尺寸与刚性形状应保持，差异如何由同一镜头解释。
- **尾巴等附肢（适用时）**：真实根部和被遮挡的连接、连续中心走向、沿途宽度、鳞片或毛流；本动作是否需要活动，哪些关键稿共用同一部件。
- **运动范围**：头部转角、四肢极值、柔性部件最大弯曲；超出当前视角时需准备什么替换件。

关键帧不按图片张数等分时间。主要运动段大致匀速，关节局部角度和肢段整体朝向同时检查；中间姿态不重复减速到零。

检查关键姿态前后各一帧及实际时间播放；对真实反向、接触建立和释放单独安排减速。袖摆和饰品的滞后不应拉开关节连接。

## 4. 部件与显露区域

按运动和遮挡拆分；始终同动且没有单独遮挡需求的细节可合并。

| 部件名 | 完整源图与坐标偏移 | 父部件 / 支点 | 刚性或可弯范围 | 前后关系及变化 | 动作中露出的新区域 | 干净底层/补绘文件 |
|---|---|---|---|---|---|---|
| | | | | | | |

每个移动部件核对：

- [ ] 完整轮廓覆盖设计的动作范围，运动中不会露出截断的关节、指尖、耳尖或衣摆。
- [ ] 原位清底去掉旧轮廓、旧肢体和随物移动的阴影。
- [ ] 提取蒙版保留高光、墨线、首饰与真实指缝；未夹带相邻物体。
- [ ] 单独检查相邻同色区域：手部未夹带脸、肩膀等肉色像素；边界沿真实外轮廓，未把内部指缝误作裁切外缘。
- [ ] 内部切边与真实外轮廓分清，接缝有足够的隐藏重叠区域。
- [ ] 逻辑上同动的前后子层共用姿势，绘制顺序可以独立安排。
- [ ] 在遮挡最复杂的中间姿态检查真实像素；需要时拆开裸肩与袖口等前后子层，共享控制点，整条公共边始终连续。
- [ ] 同一物体跨状态共用素材；替换件已经在同一坐标、光照和比例下对齐。
- [ ] 需要的表情件保留脸型、眼角、睫毛与原画笔触。
- [ ] 在实际头部倾角下检查两眼半闭、全闭的可见睫毛墨线，以及它与脸侧发丝的遮挡。
- [ ] 原图、独立部件、清底和运动合成逐一对照，描线完整，边缘没有误带邻物、旧轮廓或漏抠。
- [ ] 饰品等稳定形状独立于大幅变形衣料；关键姿态混合不产生半透明双线。

| 参数/动作含义 | 范围与极值姿势 | 谁控制它 | 哪些部件受影响 | 哪些接触或刚性部件必须保护 |
|---|---|---|---|---|

只填写当前动作实际需要的参数。为 Q版和正比各自标定数值与绑定，保留共用的含义。

动作冲突规则：主动作占用哪些部位；点击可叠加哪些回应；眨眼是否应暂停或配合；退出后回到哪个当前状态；暂停和重复输入怎样处理。

连续时钟与完成行为：哪些呼吸、提示或次级动作跨状态延续，如何保持相位；一次性动作完成后进入何种常驻状态，之后点击怎样回应，何时允许再次触发该动作。

## 6. 粗稿验证与精修范围

粗稿先验证一次最复杂的接触/遮挡变化，并跑完进入—保持—退出—中途反转。

|---|---|---|---|
| | | | |

精修以确认的统一母版为基准，记录每次局部补绘采用范围。图像生成的合成图仍需完成拆分与隐面补全，不能把生成提示词中的“分层”当作真实图层已经交付。

## 7. 最终验收与采用记录

- [ ] 日常尺寸下隐藏文字仍可辨认主要动作，细节不靠过深描线硬撑。
- [ ] 最大显示尺寸下无露洞、残留、断裂、重复肢体、错误黑边、裁切和颜色突变。
- [ ] 浅色、深色背景均检查，透明区域中没有画入棋盘格。
- [ ] 骨架、支撑与接触成立；必要时隐藏衣物检查中间姿态。
- [ ] 正反路径、接触改变、最大弯曲、闭眼与换素材时刻均已检查。
- [ ] 实际时间播放自然；可逆阶段反转不跳位置或速度，接触改变后使用已设计的恢复路径。
- [ ] 取10–20帧检查整个动作；关键姿态前后加密检查，角速度没有突然变化，起止和停顿按动作意图减速。
- [ ] 次级运动不破坏关节、接触和刚性物形状。
- [ ] 用最终打包素材验证启动、暂停恢复、重复交互与显示尺寸。
- [ ] 观察到一次性动作末帧之后：进入正确常驻状态，呼吸不跳相位，眨眼、点击及再次进入动作正常。
- [ ] 共用部件受影响的既有状态与过渡已复核。

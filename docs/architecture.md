# desktop-dragon 架构

更新日期：2026-11-04。本文描述当前发布功能、模块边界和已有验收证据。浏览器动画审阅、自动测试和原生桌面实测分别记录。

## 发布范围与产品边界

应用运行于macOS 13及以上的Apple Silicon设备，以人物动作显示全部已观察Codex会话的汇总活动。单击非休眠人物播放反馈并显示账户额度；继续点击显示当前姿态的随机台词。休眠点击只唤醒。会话列表通过右键菜单展开，不常驻占用桌面。

软件永久只读：不发送消息，不启动、继续、停止或取消会话，不批准或拒绝请求。查询包含会话状态、工具与子代理活动、账户额度与重置时间，不包含待办正文或原会话跳转。人物交互、位置和形态变化只改变本地表现。缺少来源数据时直接说明，不推算任务成功、阻塞或完成比例。

| 功能 | 数据或触发依据 |
| --- | --- |
| 待机、思考、阅读、工作 | 已观察会话与工具事件，经状态策略投影 |
| 阅读/工作待确认 | Codex已接受的异步提问，以及按问题标识匹配的回答 |
| 绘图 | 本地动作菜单 |
| 子代理双云 | 已观察到的活动子代理，并且人物处于任务场景 |
| 额度与重置时间 | 所选Codex程序当前登录账户的只读额度接口 |
| 休眠、点击反馈、变身、拖动、飞行和扒边 | 本地交互与空闲计时 |
| 会话面板 | 右键打开，显示事件摘要、活动与待答计数、来源连接信息 |

## 模块与职责

实现采用Electron 45.2.1、JavaScript ES模块、现有DOM/CSS、Canvas2D/PixiJS及HTML视频，由Electron Packager 20.3.0打包。生产依赖中的`shell-quote`用于识别命令工具的读取活动。现有动画宿主和素材直接运行在Electron页面中。

| 模块 | 职责 |
| --- | --- |
| `desktop/main/index.mjs` | 应用生命周期、透明窗口、托盘、指针命中、显示器变化、位置保存及有限IPC |
| `desktop/main/geometry.mjs` | 工作区合并、几何检查与初始位置 |
| `desktop/main/protocol.mjs` | 提供随应用交付的页面、运行模块和资产，限制资源路径 |
| `desktop/main/quota.mjs` | 只读额度查询、短期缓存和查询进程生命周期 |
| `desktop/main/sessions.mjs` | 观察新事件，区分历史与本次活动，生成会话和人物目标快照 |
| `desktop/codex-hooks/` | 接收必要元数据，执行采集开关，按完整标识归并事件；只读检查注册项数 |
| `desktop/preload/index.cjs` | 查询、订阅、布局上报与菜单接口 |
| `app/desktop/` | 桌面人物、会话面板、信息气泡、空闲计时、坐标与命中区域 |
| `app/runtime/` | 状态策略、动画宿主、渐变与圆云、手势及拖动/飞行/扒边调度 |
| `assets/animations/{state}/{form}/` | 各场景入口`scene.js`、完整贴图和动作模块 |
| `assets/shared/`、`assets/vendor/` | 共用部件、校色、问号、双云与随包动画运行库 |
| `tools/package.mjs` | 应用打包 |

进程划分遵循[Electron进程模型](https://www.electronjs.org/docs/latest/tutorial/process-model)。CrossPet与dsh-pet用于参考来源观察、桌面交互和人物呈现的职责划分；来源与授权见[第三方说明](../THIRD_PARTY_NOTICES.md)。

软件在本仓库维护。绘图、补绘、分层、关键帧与动画组装在`<art-workspace>/dragon-pet`完成，用户采纳后整体交付运行模块与素材。运行时不链接制作目录。目录和文件使用语义名称；制作来源保留真实相对路径，外部根目录使用脱敏占位符。交付范围见[资产目录](asset-catalog.md)和[交付约定](asset-delivery.md)。

## 桌面窗口与鼠标

透明原生窗口固定覆盖所有显示器工作区的并集。人物移动、渐变、变身和飞行均在窗口内部改变页面坐标，避免原生窗口与页面在不同帧切换坐标原点。人物Canvas保持自身尺寸，不创建整桌面大小的人物Canvas。

主进程将全局鼠标位置与页面上报的人物、扒边和展开面板区域比较。区域外启用`setIgnoreMouseEvents`，按住拖动时保持鼠标接收，飞行期间穿透。人物命中区域按身体范围计算；信息气泡不加入鼠标命中区域。

窗口透明、无边框、置顶、跳过任务栏，以`showInactive`显示。`focusable:false`阻止窗口获得焦点，`acceptFirstMouse:true`接收未激活时的首次点击，`type:'panel'`采用macOS非激活面板。应用隐藏Dock图标，并允许窗口覆盖多屏范围。[Electron窗口选项](https://www.electronjs.org/docs/latest/api/base-window)

页面以虚拟桌面工作区原点计算位置，Electron屏幕坐标使用DIP逻辑像素。屏幕通知先比较实际工作区几何；相同布局不重置人物。布局变化时更新窗口范围、换算位置并保留当前动作：飞行继续原播放进度，扒边对齐新边缘，普通姿态限制在可见区域。“回到屏幕内”菜单明确结束当前位移动作。[Electron screen](https://www.electronjs.org/docs/latest/api/screen)

位置与设置保存在Electron用户数据目录；开发运行使用`.local/desktop/`。退出时关闭观察定时器、指针检查与托盘；页面销毁时解除订阅并销毁动画宿主。隐藏时暂停动画，场景切换结束后销毁出场实例。

## 事件到人物状态

```text
Codex已注册钩子 → 接收器检查disabled → events/*.json元数据
                                            ↓
                                  主进程会话观察器
                             历史记录 + 本次活动归并
                                            ↓
                   会话摘要 + 活动计数 + 待答问题 + 人物目标
                                            ↓ 受限IPC
                        桌面人物 / 查询面板 / 子代理双云
```

接收器在启动及保存前检查采集开关；停用时成功退出，启用时原子写入单个事件后退出，不向Codex输出决策。桌面每秒检查新文件，无变化时不重建快照。`state.mjs`按完整会话、轮次、工具调用和代理标识归并，工具逐调用配对，一个工具结束不会清除其他运行工具。

应用启动前的记录属于历史，可在面板查看，但不恢复为正在执行。切换数据目录或重新开启采集时建立新的观察起点。没有持续事件既不表示任务完成，也不证明客户端断连。

快照包含`sessions`、`activity`、`observedSince`、`connection`、`registration`、`capabilities`与`error`。活动计数和待答问题数分别归并。连接信息区分采集开关、历史最近事件、本次接收量和注册项数；注册存在不代表已受信或当前聊天已连接。钩子不提供账户用量、成功完成或准确根任务计数，额度走独立查询接口。

场景选择遵循以下规则：

- 明确的读取工具归阅读，包括实际捕获的`webrun`、`view_image`及代码中列出的只读工具。
- Bash命令在接收器内存中用`shell-quote`解析；明确的文件检索、读取及纯读取管道归阅读，只保存`tool_kind`，不保存命令正文、路径或检索词。混合写入与任意脚本归一般工作。
- 本轮有活动且没有运行工具时显示思考；这不表示捕获了模型的私有思考内容。
- 当前轮刚结束的工具动作保留3秒供辨认，实际活动工具数仍归零。新运行工具立即接管；中断、结束、新轮与关闭采集清除展示缓冲。计时到期先刷新落盘事件，再决定姿态，避免睡眠唤醒后重播已停止活动。
- 多会话有工具同时运行时，当前场景仍有实际工具支持就保持，否则选择最近运行工具；工具优先于思考与短动作缓冲。
- `Stop`结束该轮活动计数，不代表成功。全部会话无活动且无待答问题时回待机。停止的旧工具不会随新调用恢复。
- 已接受的异步提问优先显示待确认，使用提问前的阅读或工作姿态；没有前置工具时使用工作待确认。回答完成后重新选择当前活动。
- 绘图由本地动作菜单触发。未知工具保持一般工作，权限请求事件不能单独启用审批等待。

### 异步提问与子代理

`request_user_input_async`的明确接受结果建立待答问题，按同会话的完整调用标识与问题索引匹配回答。多个问题逐题解除，跨轮回答仍按原问题归并。工具返回、普通消息、Stop和Interrupt不代表问题已回答；SessionEnd清除该会话待答。历史记录不恢复待答。只保存问题数量、接受标记和回答对应标识，不保存题目、选项或答案。

子代理使用独立轮次，不取代主轮次。会话汇总主轮次与仍运行子代理的工具；主轮次Stop不清除独立子代理，SubagentStop清除自身轮次活动。活动子代理数量大于零且人物处于任务场景时显示双云，两云同步环绕，点击人物触发一圈。云朵造型不代表已核实的模型品牌或两项任务；终端和画稿属于装饰动画，数量不作为根任务计数。

### 数据目录、采集开关与隐私

开发运行默认读取`.local/codex-hooks/`，打包应用默认读取`app.getPath('userData')/codex-hooks/`。菜单选择包含`events/`的数据目录，须与接收器实际写入目录一致。应用不自动安装、注册或信任钩子。

“启用 Codex 状态采集”通过`control.mjs`增删数据目录中的`disabled`标志。关闭后停止新记录与轮询，已有事件归历史，人物回待机；开启后从新起点观察，不恢复旧活动。该开关不修改已注册命令、信任或其他程序的钩子配置。

接收器只保存必要元数据，不保存提示词、命令正文、工具结果或凭据。页面不接触原始会话正文。`.local/`不提交、不打包，也不经资源协议暴露。公开记录使用匿名标识和相对时间。

注册与接收状态的区分参考CrossPet的[注册管理](https://github.com/lokicorvus/crosspet/blob/main/tools/integrate.py#L327)与[设置显示](https://github.com/lokicorvus/crosspet/blob/main/app/web/settings.html#L235)。本项目的运行时采集标志同时控制新记录和桌面跟随，实际比较及验收见[钩子记录](codex-hooks-implementation.md)。

## 点击气泡与额度

`app/desktop/bubble.js`管理单个气泡的内容、定位与动效，`dialogue-lines.js`保存用户确认的状态台词。气泡隐藏时点击非休眠人物先查询额度，显示期间继续点击随机换句，多句分组排除上一句。待机/休眠、拖动/扒边分别选词，按当前可见姿态决定文案，不按后台排队目标提前换词。

额度显示4秒、台词显示3秒后收起；冷查询期间保持加载提示，结果到达后计时。旧查询不会覆盖已经切换的台词。第二次快速点击延迟420ms推进，第三击取消气泡并变身。拖动、飞行、变身、隐藏与菜单操作收起气泡。休眠点击及整个唤醒过程中不查询、不弹气泡，以动画控制器的实际`waking`状态判定；动作结束后再次点击恢复额度流程。

额度气泡宽184px、标题18px；台词字号14px、行高21px，按文字自然宽度收缩，最大164px、内边距8px/9px，超过最大行宽才换行。沿用300ms渐显弹出、140ms换内容退场和210ms渐隐收回。气泡靠近头顶，空间不足时侧排并限制在工作区内；范围计入布局上报但保持鼠标穿透。

`desktop/main/quota.mjs`通过所选Codex程序的stdio app-server执行`initialize`、`initialized`与只读`account/rateLimits/read`。只读取实际返回的额度窗口，由`100-usedPercent`得到剩余比例，保留缺失值；窗口名依据`windowDurationMins`，`resetsAt`的Unix秒转换为本地日期与距重置时长。不读取凭据、不创建或控制会话、不执行额度重置。[账户额度接口](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)

查询按点击触发，30秒内复用成功快照，到达任意窗口重置时间后重新读取；并发查询共用结果。完成、失败、20秒超时和退出时关闭该查询子进程。页面只收到额度窗口、获取时间和安全提示，不收到账户标识或原始服务错误。默认执行PATH中的`codex`，也可通过“选择 Codex 程序…”保存本机可执行文件位置。账户取决于所选程序的登录状态，与钩子目录分别配置。

## 动画、休眠与边缘交互

人物尺寸按身体尺度校准，200px Q版与400px正比是原始基准。当前站立思考与拖动使用144档，飞行136.8档，其余Q版162档，正比324档，由`display-policy.js`统一提供。这些数值不是素材整体高度；各姿态保留身体比例、眼部锚点和1000px审阅能力。

同场景等待往返播放专用动作；同比例跨场景渐变；跨比例使用无字圆云与渐变。阅读、工作、绘图通过连续三击或右键切换形态。普通点击叠加480ms轻微回弹，纵向压缩1.8%、回弹0.9%，连续点击不无限叠加。扒边沿用自身0.64秒回弹、1.35秒振翅、4.7秒呼吸及5.7秒眨眼。

`idle-sleep.js`使用120秒单次定时器：跟随模式下、来源正常、零活动且无待答、人物处于待机并且没有交互时进入休眠。重复空闲快照不推迟计时，也不唤醒人物。点击或拖动重新计时，真实活动恢复任务姿态。拖动、飞行、扒边、动画交接、隐藏和手动动作审阅期间停止休眠计时。

`PetInteraction`在按下后移动超过约6个逻辑像素时进入拖动，取消本轮点击。拖动、飞行和扒边期间继续接收最新任务目标，拖回后应用最新目标，不补播旧状态。手动动作菜单退出跟随，“跟随会话状态”恢复任务展示。

拖动开始时双云播放收起动作，退出中的云不随拖拎暂停；飞行与扒边期间隐藏。放下恢复任务姿态后，仍有活动子代理才重新出现。双云环绕一圈4秒、常驻周期18秒，Q版轨迹半径为原值0.85倍；云朵尺寸公式乘1.22，结合人物缩放后实际约放大10%。

左右外侧边缘触发范围为80px，判定与高亮共用`DRAG_EDGE_WIDTH`，使用释放锚点到屏幕边缘的距离，不使用视频宽度。相邻显示器接缝重合范围允许继续跨屏拖动，上下边缘不触发。交互链为任务姿态→拖拎→飞行→扒边→向内拖拎→最新任务姿态。

飞行采用5640源片制作的60fps透明视频，源时长约4.834秒，以1.5倍速播放约3.22秒。首帧对齐松手眼部锚点，播放中保持原视频路径与人物尺度；左侧整段镜像。视频清晰度、抠像及补帧残影限制见[资产目录](asset-catalog.md)，软件过渡不改变这些源片限制。

## 资源与接口边界

页面只加载`dragon://app/desktop/index.html`及随包资源。自定义协议仅映射`app/desktop/`、`app/runtime/`与`assets/`，检查解析后的路径范围；仓库根目录和本地事件不可通过协议读取。

Electron启用`contextIsolation`和`sandbox`，关闭页面Node集成，保留网页安全检查，阻止导航、新窗口与权限请求。CSP限制脚本、网络和媒体来源。预加载仅暴露`bootstrap`、`sessions`、`quota`、`report`、`menu`及布局、动作、会话订阅；主进程检查发送页面与参数，不暴露任意文件、shell、URL打开或通用IPC转发。[Electron安全建议](https://www.electronjs.org/docs/latest/tutorial/security)

来源事实归并、人物状态策略和动画资源各自独立。新增来源须提供实际可核实的事件；新增动作扩展场景入口与资源登记。现有接口不包含会话控制，也不以制作区演练数据冒充客户端能力。

## 构建与发布

`npm start`运行桌面应用；`npm test`检查状态归并、提问生命周期、交互、几何、额度与观察器逻辑；`npm run package`生成macOS应用。打包排除`.local/`、制作参考、测试、工具及开发依赖，不含Developer ID签名或Apple公证。

`.github/workflows/release.yml`以与`package.json`一致的`v`标签触发，在macOS arm64运行测试并打包ZIP，使用`docs/releases/{版本号}.md`作为说明。上传草稿及安装包后公开；带预发布后缀的版本标为GitHub pre-release，不标为Latest。当前版本入口见[README](../README.md)。

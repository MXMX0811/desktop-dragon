# desktop-dragon 架构与实施状态

更新日期：2026-11-03。本文区分代码已实现、已取得的运行证据及仍需验证的能力；浏览器动画审阅不能代替真实桌面验收。

## 产品边界

桌宠显示全部已观察会话的汇总活动。普通单击只播放人物反馈，休眠时单击唤醒；会话面板通过右键菜单展开。菜单也提供本地动作审阅和恢复跟随状态。人物反馈、形态和位置变化均只影响桌宠。

软件永久只读，不向会话发送消息，不开始、继续、停止、取消任务，不批准或拒绝请求。目标查询能力包括状态、用量、待办和原会话入口；当前已接入事件状态，用量、待办正文和跳转尚未实现。缺少数据时直接说明，不制造成功、阻塞或待办事实。

人物沿用分层动画：Q版200px、正比400px为原身体尺度基准，各姿态按身体比例校准。2026-11-03按用户要求，站立思考、拖动缩至原尺度80%，起飞再缩至这一尺寸的95%（原尺度76%，152档），其余状态缩至90%；统一通过`app/runtime/display-policy.js`的`displaySize()`提供尺寸。左右边缘触发与高亮变量共用80px贴边范围，拖动与飞行继续按眼部锚点对齐；命中区域、变身云和子代理云按实际元素范围计算。素材仍支持1000px审阅。同场景等待往返使用专用动作；同比例跨场景渐变，跨比例使用无字圆云与渐变。飞行单独播放用户采纳的60fps透明视频，以1.5倍速播放。

## 模块与职责

采用Electron 45.2.1、JavaScript ES模块、现有DOM/CSS、Canvas2D/PixiJS及HTML视频；由Electron Packager 20.3.0打包。当前没有引入TypeScript、UI框架或额外状态库。

| 模块 | 职责 |
| --- | --- |
| `desktop/main/index.mjs` | 应用生命周期、固定透明窗口、托盘、全局指针命中、显示器变化、位置保存和有限IPC |
| `desktop/main/geometry.mjs` | 工作区合并、矩形验证和初始位置选择 |
| `desktop/main/protocol.mjs` | 提供随应用交付的页面、运行模块和资产，限制资源路径 |
| `desktop/main/sessions.mjs` | 按采集开关启动观察，区分历史与本次事件，生成只读会话、连接信息及动画目标快照 |
| `desktop/codex-hooks/` | 接收有限元数据，检查采集标志并落盘，按完整ID归并；只读检查本项目注册项数 |
| `desktop/preload/index.cjs` | 暴露明确的查询、订阅、布局上报和菜单接口 |
| `app/desktop/` | 桌面人物宿主、会话面板、坐标转换和人物命中区域 |
| `app/runtime/` | 共用状态策略、动画宿主、渐变、圆云、手势和拖动/飞行/扒边调度 |
| `assets/animations/{state}/{form}/` | 各场景运行入口`scene.js`及完整贴图和动作模块 |
| `assets/shared/`、`assets/vendor/` | 共用部件和动画、校色、气泡、双云及随包运行库 |
| `tools/package.mjs` | 当前主机平台应用打包 |
| `tools/preview.py` | 独立浏览器审阅服务器 |

软件在`<repository>`维护。绘图、补绘、分层、关键帧和动画组装留在`<art-workspace>/dragon-pet`。采用后交付完整运行模块及来源记录，不在运行时链接制作目录。动画目录和文件名使用语义名称，不带制作版本或候选后缀；来源记录保留制作区相对路径与真实文件名，外部根目录使用脱敏占位符。

Electron直接承接既有浏览器动画，提供macOS和Windows共用的窗口与Chromium运行环境。进程划分遵循[Electron进程模型](https://www.electronjs.org/docs/latest/tutorial/process-model)。CrossPet和dsh-pet用于参考来源观察、桌面交互与人物呈现的职责划分，当前继续复用本项目已有动画宿主。

## 桌面显示、穿透与焦点

原生透明窗口覆盖所有显示器工作区的并集。正常移动、渐变、变身和飞行都在固定窗口内部改变人物坐标，不逐帧调整原生窗口范围。这样原生窗口和页面不会在不同帧切换坐标原点。人物Canvas仍保持自身尺寸，不绘制一个整桌面大小的人物Canvas。

主进程读取全局鼠标位置，与页面报告的人物、扒边和展开面板区域做命中判断。区域外启用`setIgnoreMouseEvents`，拖动按住时保持鼠标接收，飞行期间穿透。命中区域使用人物身体范围，避免透明素材留白挡住后面的应用。

窗口设置为透明、无边框、置顶、跳过任务栏，并使用`showInactive`显示。`focusable:false`阻止窗口获得焦点；macOS的`acceptFirstMouse:true`让未激活窗口仍能把首次点击交给页面，`type:'panel'`使用原生非激活面板样式。macOS另允许窗口超过单屏范围并隐藏Dock图标。这些设置采用[Electron官方窗口选项与panel说明](https://www.electronjs.org/docs/latest/api/base-window)，鼠标穿透及不激活应用的实际效果仍须在各平台验收。

页面坐标以虚拟桌面工作区原点计算，Electron屏幕坐标采用DIP逻辑像素。显示器增加、移除或工作区变化时，更新窗口范围并将人物放回可见工作区，终止当前位移动作。异形屏幕排列、跨屏和混合缩放尚需实测。[Electron screen](https://www.electronjs.org/docs/latest/api/screen)

位置与设置保存于Electron用户数据目录。开发运行使用仓库`.local/desktop/`；打包应用使用平台正常的Electron用户数据目录。退出时关闭观察定时器、指针检查和托盘；页面销毁时解除订阅并销毁动画宿主。隐藏时暂停现有动画，切换结束销毁出场场景。

## 只读事件到动画的数据链

```text
Codex已注册钩子 → 接收器检查disabled → events/*.json元数据
                                      ↓
                            主进程会话观察器
                      历史记录 + 本次观察的事实归并
                                      ↓
                  会话列表 + 活动计数 + 人物目标快照
                                      ↓ 受限IPC
               桌面人物宿主 / 右键查询面板 / 子代理双云
```

接收器在启动及保存前检查采集开关，停用时成功退出；启用时完成单个事件的原子落盘后退出，不向Codex输出决策。启用的桌面观察器每秒检查一次目录，只读取新文件；没有变化时不重建或推送快照。复用`desktop/codex-hooks/state.mjs`的归并逻辑，工具按调用ID配对，避免某个工具结束清空同轮其他工具。

应用启动前已经落盘的事件标记为历史。它们可供面板查看，但当前活动数清零；只有本次观察的新事件能推进实时人物状态。切换读取目录同样从新的观察起点区分历史。没有持续事件不等于客户端断连，也不等于任务结束。

快照由`{sessions, activity, observedSince, connection, registration, capabilities, error}`构成。`activity`包含人物场景、已观察活动会话数、工具数、代理数和是否暂停表现。`connection`区分开关、含历史的最近事件、本次最近事件及接收条数；`registration`仅报告配置中的本项目事件项数。`capabilities`明确标记当前没有账户用量、待办、可信等待、成功完成和准确根任务计数能力。

当前场景策略：

- 已核实的明确阅读工具名归阅读，包括实际捕获的`webrun`、`view_image`及列入代码的只读查询工具。
- 接收器在内存中用`shell-quote`解析Bash的`tool_input.command`，将明确的文件检索、读取命令及纯读取管道归阅读；只落盘`tool_kind`类别，不保存命令、检索词、文件路径或正文。混合写入和任意脚本仍为一般工作。
- 已观察本轮活动但无运行工具时显示思考。刚完成的当前轮工具保留3秒动作展示，避免亚秒级工具在一次扫描中被吞掉；活动工具数仍为0。单次定时器到期回思考，新实际工具立即接管；中断、结束、新轮与关闭采集清除缓冲。这是显示策略，不是捕获模型私有思考。
- 实际运行工具优先于其他会话的思考和短动作缓冲；当前场景仍有实际工具支持时保持，否则选择最近运行工具。没有运行工具时只展示最近完成动作，不排队重播。
- `Stop`结束该轮的活动计数；所有会话均无活动时人物回到待机。查询面板仍标示已观察停止、结果未判定，不将停止等同于成功。新的真实工具或用户输入可恢复活动，已停止的旧工具不随之恢复。`PermissionRequest`记录为已观察权限请求，不能据此进入待确认。
- 绘图和待确认已有表现素材，但缺少核实的自动来源时只提供本地动作审阅。未知工具不能仅凭模糊名称启用专用动作。

子代理按完整session_id、turn_id、agent_id配对，独立轮次不取代主轮次。会话汇总当前主轮次和仍运行子代理的工具；主轮次Stop不清除独立子代理，SubagentStop清除自身轮次活动。真实子代理计数大于零且处于任务场景时显示双云，两云同步环绕，点击人物触发一圈。两种云朵造型不表示已核实两个品牌模型，也不直接代表两个子代理。终端和画稿当前仍有装饰性动画；准确根任务归属尚未核实，不能把装饰数量当任务计数。

### 数据目录

开发运行默认读取仓库`.local/codex-hooks/`；打包应用默认读取`app.getPath('userData')/codex-hooks/`。菜单“选择 Codex 钩子目录…”选择包含`events/`的已有数据目录并保存选择，不注册、修改或信任任何钩子。打包应用若要显示本机既有接收器的数据，应选择接收器正在写入的目录。

接收器只保存必要事实字段，不保存提示词、命令正文、工具结果或凭据。页面不访问文件系统，不接触原始会话正文。`.local/`不提交、不打包，也不通过资源协议提供。

### 采集开关与连接信息

右键和托盘菜单“启用 Codex 状态采集”通过`control.mjs`增删选定数据目录中的`disabled`标志。关闭后，主进程重建不轮询的观察器，将全部已有记录作为历史、实时计数归零，并恢复人物待机。开启后重建观察器，以当前时间为新起点；关闭前的未结束工具不恢复为实时活动。标志随目录持久保存，桌面选择的目录必须与接收器写入目录相同。

采集开关沿用已注册命令，不修改`hooks.json`及其他程序的钩子配置。应用只读检查本项目注册事件数；注册项数不等于信任，最近事件可能来自历史，均不能冒充当前聊天已经连接。官方只读`hooks/list`在本轮核实的12项受信结果属于人工验收证据，应用未实现信任接口。

参考CrossPet的[注册管理](https://github.com/lokicorvus/crosspet/blob/main/tools/integrate.py#L327)与[设置显示](https://github.com/lokicorvus/crosspet/blob/main/app/web/settings.html#L235)，将注册存在和实际收到事件分别显示。CrossPet接入/撤销会增删配置；它的自动启动关闭标志只阻止启动，开发暂停只停止人物更新。此处用运行时标志停止新记录，已加载命令的旧聊天同样受控。应用没有自动安装、撤销、重启或信任功能，具体源码比较见[钩子记录](codex-hooks-implementation.md)。

### 后续来源能力

审批需要核实请求开始、真实阻塞与解除的完整链路，再启用自动等待表现。准确根任务数需要核实父会话与子代理归属。额度、待办和原会话入口按实际可用的只读接口逐项接入；当前没有启动app-server查询或读取会话目录。现有JSONL桥继续用于事件演练，不代表拥有原客户端的完整实时流。

dsh、ChatGPT等来源须分别验证它们实际提供的事件和查询能力，不承诺一个监听器覆盖所有产品。新增来源输出已有事实结构，新增人物动作扩展动画宿主和资源登记，两者职责保持独立。

## 点击、形态与边缘交互

`PetInteraction`复用已有手势判定和连续时间轴：按下移动超过约6个逻辑像素开始拖动并取消本轮点击；普通单击立即反馈，睡眠时优先唤醒；连续三击在阅读、工作、绘图切换形态。右键打开原生菜单，选“查看会话状态”才展开面板。面板关闭后不持续刷新其列表。

人物形态偏好与任务事实分开。拖动、飞行和扒边期间继续接收最新目标，回到正常显示时采用最新目标，不补播过期状态。菜单动作审阅会暂时退出跟随；“跟随会话状态”恢复订阅目标，所有操作均不写回原会话。

左右外侧边缘区域使用80px贴边范围，释放锚点进入该区域并松手后才起飞。范围以释放锚点到屏幕边缘的距离判断，视频尺寸不参与此计算。鼠标处于相邻显示器接缝重合范围时允许继续跨屏拖动，不触发飞行；不处理上下边缘。流程为任务姿态→拖拎→飞行→扒边→向内拖拎→最新任务姿态。正比进入Q版拖拎使用圆云，同形态交接使用渐变。

飞行用松手时的眼部锚点对齐视频首帧；播放中保持原视频轨迹，不按每帧包围盒缩放。右侧使用原方向，左侧整段镜像，视频结束后接扒边。固定原生窗口已容纳动作区域，飞行不再触发原生窗口临时扩缩。视频源片的清晰度、裁切和抠像限制仍由资产记录说明，软件过渡不掩盖这些限制。

## 页面与IPC权限

页面只加载`dragon://app/desktop/index.html`及随应用交付的资源。自定义协议只映射`app/desktop/`、`app/runtime/`与`assets/`，校验解析后的路径范围，仓库根目录及本地事件不可通过协议访问。

Electron启用`contextIsolation`、`sandbox`，关闭页面Node集成，保留网页安全检查，阻止导航、新窗口及权限请求。CSP限制脚本、网络和媒体来源。预加载仅暴露`bootstrap`、`sessions`、`report`、`menu`及布局、动作、会话订阅；主进程校验发送页面与参数，不暴露任意文件读取、shell、URL打开或通用IPC转发。[Electron安全建议](https://www.electronjs.org/docs/latest/tutorial/security)

原会话跳转尚未实现。以后若接入，入口应由已核实来源和会话ID生成，不接受页面任意URL或命令。会话控制接口始终不加入。

### 异步提问的接入边界

当前桌面的待确认动画可在审阅菜单使用，正式状态投影尚未自动触发它。真实`request_user_input_async`调用会立即产生PreToolUse/PostToolUse，表示提问工具已返回，并不表示用户已回答；现有钩子元数据也不包含对应问题的提交或跳过标识。因此不能用PostToolUse、超时或任意后续消息推断解除。接入需要只读的问题生命周期（问题标识、待答、已提交、已跳过、轮次结束），并将异步待答与会话真正阻塞分别表示。当前未建立该来源，不将演练桥作为真实客户端接入证据。

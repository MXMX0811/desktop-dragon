# Desktop Dragon 0.1.0-alpha.1

本版提供 macOS Apple Silicon ZIP，应用包要求 macOS 13及以上。

## 功能

- 点击反馈、拖动、Q 版与正比切换、左右边缘飞行与扒边。
- 子代理小云随拖动收起；放下后，仍有子代理活动时重新出现。
- 手动接入 Codex 后，以人物动作显示已观察到的会话、工具和子代理活动；右键打开会话状态面板。
- 托盘及右键菜单提供动作审阅、采集开关、显示/隐藏、回到屏幕内和退出。

## 安装与 Codex 接入

下载本次 Release 的 macOS arm64 ZIP，解压后将 `Desktop Dragon.app` 移到“应用程序”并打开。桌宠本体无需安装 Node.js 或 Python。macOS 下不显示 Dock 图标，可通过人物右键或菜单栏托盘操作。

此版本不含 Developer ID 签名和 Apple 公证。首次打开被系统阻止时，确认下载来源后，按 [Apple 官方说明](https://support.apple.com/en-us/102445)，在“系统设置 → 隐私与安全”选择“仍要打开”，再确认打开。

接入 Codex 需另外安装 Node.js 22.13+，取得并保留本仓库、运行 `npm ci`，按[钩子接入说明](https://github.com/MXMX0811/desktop-dragon/blob/v0.1.0-alpha.1/desktop/codex-hooks/README.md)手动注册并信任接收器。桌宠与接收器须选择同一数据目录；以面板“本次接收”增加确认接通。未接入时可通过右键菜单审阅动作。

接入永久只读：不发送消息、控制会话或处理审批；只保存必要事件元数据，不保存提示词、命令正文或工具结果。关闭采集后停止新增记录，重新开启只观察新活动。

## 已知限制

- 本版待确认和绘图动画由动作菜单触发；查询范围为已观察会话、工具和子代理事件状态。
- 观察到停止不代表任务成功；历史记录、已注册钩子均不能证明当前聊天已接通。
- 本版原生验收范围为受测macOS单屏环境；多屏、混合缩放、长时资源开销和复杂嵌套子代理不包含在该证据范围内。

实现范围见[架构说明](https://github.com/MXMX0811/desktop-dragon/blob/v0.1.0-alpha.1/docs/architecture.md)，素材和运行库来源见[第三方说明](https://github.com/MXMX0811/desktop-dragon/blob/v0.1.0-alpha.1/THIRD_PARTY_NOTICES.md)。

# Desktop Dragon 0.1.0-alpha.2

适用于 macOS 13 及以上的 Apple Silicon（M 系列芯片）Mac。

## 本版更新

- **额度与对话气泡**：清醒时单击显示 Codex 账户剩余额度、距重置时长和本地重置日期；继续点击随机显示当前姿态的预置台词。气泡渐显弹出、渐隐收回，台词按文字宽度收缩，超过最大行宽自动换行。
- **自动待确认**：收到已接入的 Codex 异步提问后，优先展示阅读或工作待确认动作；按对应回答逐题解除等待，全部待答问题解除后恢复当前任务。统一 Q 版与正比的问号大小。
- **休眠与唤醒**：跟随状态时，待机两分钟且没有人物交互会自动休眠。休眠点击只唤醒，打哈欠结束后再次点击显示额度。
- **人物反馈**：点击轻微回弹；扒边状态有呼吸、眨眼、点击振翅。调整人物尺寸及子代理双云大小、环绕速度。
- **桌面状态修复**：改善系统唤醒、显示器布局通知与过期事件计时交错时的状态保持，扒边期间继续接收任务，拖回后应用最新活动。
- **应用与文档**：采用 Q 版龙娘头像图标，README 展示多组动画预览；交付内容集中为运行代码、资产与使用维护文档。

## 安装

下载本次 Release 的 `desktop-dragon-0.1.0-alpha.2-macos-arm64.zip`，解压后将 `Desktop Dragon.app` 移到“应用程序”并打开。使用桌宠本体无需安装 Node.js 或 Python。已运行桌宠时，通过人物右键或菜单栏菜单退出，再替换应用。

应用包不含 Developer ID 签名和 Apple 公证。首次打开被系统阻止时，确认下载来源后，按 [Apple 官方说明](https://support.apple.com/en-us/102445)，在“系统设置 → 隐私与安全”选择“仍要打开”。

## Codex 接入

- **状态采集**：安装 Node.js 22.13 或更新版本，保留本仓库并运行 `npm ci`，按[钩子接入说明](https://github.com/MXMX0811/desktop-dragon/blob/v0.1.0-alpha.2/desktop/codex-hooks/README.md)注册并信任接收器。桌宠与接收器使用同一数据目录。
- **升级接收器**：替换应用不会更新外部接收器。将原钩子命令指向的仓库更新至本版并运行 `npm ci`；若脚本路径改变，更新钩子命令并重新审阅信任。以会话面板“本次接收”增加确认接通。
- **额度查询**：安装支持 `account/rateLimits/read` 的 Codex CLI 并登录 ChatGPT 账户；可通过右键“选择 Codex 程序…”指定可执行文件。额度查询与钩子采集分别配置。

桌宠只读取事件和额度，不发送消息、控制任务或处理审批，不保存提示词、命令正文、工具结果或登录凭据。待确认对应 `request_user_input_async` 及其回答回调；绘图动作通过右键菜单展示。停止事件不表示任务成功，历史事件和注册项数不表示当前会话已接通。

完整使用方法见 [README](https://github.com/MXMX0811/desktop-dragon/blob/v0.1.0-alpha.2/README.md)，素材与运行库来源见[第三方说明](https://github.com/MXMX0811/desktop-dragon/blob/v0.1.0-alpha.2/THIRD_PARTY_NOTICES.md)。

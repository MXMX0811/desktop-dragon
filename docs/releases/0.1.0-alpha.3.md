# Desktop Dragon 0.1.0-alpha.3

适用于 macOS 13 及以上的 Apple Silicon（M 系列芯片）Mac，提供 DMG 安装包。

## 本版更新

- **白天与夜间问候**：06:00–18:00递咖啡，18:00–次日06:00抱枕道晚安。每个时段首次空闲见面时播放一次，启动、唤醒与恢复显示共用这一规则。递咖啡点击时闭眼开口笑并振翅；晚安点击时慢眨眼。右键“状态审阅”可点播两种问候。
- **问候与任务衔接**：工作、待确认和拖动优先；问候结束后继续跟随最新会话状态。隐藏时结束问候，拖动仍接入飞行、扒边和拖回流程；重复点击不会无限延长停留。
- **内存与渲染优化**：按实际显示尺寸分配画布，缩小待机局部绘制区域，释放离场贴图及扒边时的后台任务画面；会话观察器增量处理事件，按会话保留必要摘要，分批读取历史记录。
- **状态识别修复**：排除明确无持久化记录的临时分叉，减少切换闲置聊天时误入思考的情况；普通会话、持久化分叉、子代理和待回答问题继续按原有规则跟随。
- **安装与预览**：使用DMG拖放安装；README中可拉起子代理的场景展示双云同步环绕。

## 安装与更新

1. 下载本次Release的 `desktop-dragon-0.1.0-alpha.3-macos-arm64.dmg`。
2. 已运行桌宠时，通过人物右键或菜单栏菜单退出应用。
3. 打开DMG，将 `Desktop Dragon.app` 拖到“应用程序”快捷入口；更新时替换旧应用，再打开。

应用包含运行环境与素材，使用桌宠本体无需安装Node.js或Python。应用包不含Developer ID签名和Apple公证。首次打开被系统阻止时，确认下载来源后，按[Apple官方说明](https://support.apple.com/en-us/102445)，在“系统设置 → 隐私与安全”中选择“仍要打开”。

## Codex接入

- **状态采集**：安装Node.js 22.13或更新版本，取得并保留本仓库、运行 `npm ci`，按[钩子接入说明](https://github.com/MXMX0811/desktop-dragon/blob/v0.1.0-alpha.3/desktop/codex-hooks/README.md)注册并信任接收器。桌宠与接收器选择同一数据目录。
- **接收器更新**：替换应用不会更新外部接收器。将钩子命令指向的仓库更新至本版并运行 `npm ci`；脚本路径改变时更新命令并重新审阅信任。以会话面板“本次接收”增加确认接通。
- **额度查询**：安装支持 `account/rateLimits/read` 的Codex CLI并登录ChatGPT账户；可通过右键“选择 Codex 程序…”指定可执行文件。额度与钩子采集分别配置。

桌宠只读取事件与额度，不发送消息、控制任务或处理审批，不保存提示词、命令正文、工具结果或登录凭据。待确认对应已接入的异步提问及其回答回调。明确无持久化记录的临时侧聊也属于临时分叉排除范围。

使用方法见[README](https://github.com/MXMX0811/desktop-dragon/blob/v0.1.0-alpha.3/README.md)，资产来源见[第三方说明](https://github.com/MXMX0811/desktop-dragon/blob/v0.1.0-alpha.3/THIRD_PARTY_NOTICES.md)。
